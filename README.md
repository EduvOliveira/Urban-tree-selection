# Urban-tree-selection

Supplementary information for the manuscript  
**"Functional and climate-based selection of tree species for resilient urban afforestation**,  
submitted to *Urban Ecosystems"*.

This repository provides all data and code necessary to reproduce the analyses 
presented in the manuscript.

## Project overview

Urban trees play a role in climate adaptation and mitigation by providing ecosystem services 
such as carbon sequestration and microclimate regulation. 

This project develops a framework for selecting native tree species for urban afforestation by integrating 
species functional traits, ecosystem service indicators, and current and future climatic suitability. 

The approach was applied to municipalities across Sergipe, northeastern Brazil, generating recommendations 
of tree species for urban planting based on current and future edaphoclimatic conditions and ranked according 
to their carbon storage potential.

## Instructions
